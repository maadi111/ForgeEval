# Start Here

## First milestone

Implement B1 completely before building the other benchmarks.

### Deliverables

1. Build a realistic forecasting repository with intentionally leaked features.
2. Provide a clear candidate-facing problem statement that only exposes the symptom.
3. Create a correct reference solution.
4. Create an independently designed alternative solution.
5. Create public tests that are helpful but incomplete.
6. Create hidden tests for temporal integrity and unseen data.
7. Create negative controls for hardcoding and memorization.
8. Run all solutions in Docker.
9. Produce structured score reports.
10. Document why each hidden test exists.

## Then

Repeat the same process for serving, retrieval drift, adversarial grading, and GPU optimization.

## Portfolio standard

The final GitHub repository should contain architecture diagrams, benchmark specifications, reproducibility instructions, sample grader output, CI, performance measurements, and a short demo.

# Benchmark Roadmap

## B1 — Point-in-Time Feature Leakage
Difficulty: Medium. Skills: pandas, feature engineering, temporal validation, model evaluation, debugging.

## B2 — Retrieval Drift
Difficulty: Medium/Hard. Skills: embeddings, retrieval, drift, evaluation, performance.

## B3 — Broken Model Serving
Difficulty: Hard. Skills: Python, APIs, model inference, batching, serialization, debugging.

## B4 — GPU Inference Optimization
Difficulty: Hard. Skills: PyTorch, CUDA, GPU profiling, memory, throughput, mixed precision. Only claim these in a CV after implementation and validation.

## B5 — Adversarial Grading
Difficulty: Hard. Skills: testing, adversarial thinking, hidden tests, negative controls, benchmark design.

## Suggested order

1. B1
2. B3
3. B2
4. B5
5. B4
6. Agent runner
7. Kubernetes deployment
